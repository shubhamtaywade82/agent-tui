# Agentic TUI

A reactive terminal user interface (TUI) for local AI agents powered by Ollama, InkUI, and MCP.

## Features
- **InkUI Terminal Harness**: React 19 + Ink terminal interface with responsive tabs, accordion streams, and toast alerts.
- **Model Context Protocol (MCP)**: Persistent memory, filesystem tools, time, git, fetch, and sequential thinking tools.
- **Engineering Skills**: Discovers and loads guidelines from `ruby-agent-skills` (`list_skills`, `read_skill`).
- **Interactive Modals**: Instant switching for `/model`, `/skills`, `/tools`, `/mcp`, and `/clear`.
- **Advanced Prompting**: Inline ghost text autocomplete, history cycling, and live token/char counters.

## Quick Start
```bash
npm install
npm run build
npm start
```
